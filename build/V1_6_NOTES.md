# War Room v1.6.0

Major command-center release.

- Adds a native Windows `War Room.exe` launcher compiled by GitHub Actions.
- Embeds the existing official `WarRoom.ico` Orc-face icon into the EXE.
- Keeps `Launch War Room.bat` as an emergency fallback only.
- Makes the command sidebar functional with smooth navigation.
- Adds a command deck for roster, raid groups, dossier, and raid intelligence.
- Adds stronger interaction polish for raiders, groups, and command surfaces.
- Validates JavaScript, PowerShell updater syntax, and required package files before publishing.
